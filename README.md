# Система управления персоналом

## Описание проекта

Учебный проект, разработанный с использованием
фреймворка Django.

Проект предназначен для организации и хранения
информации о рабочих местах и сотрудниках.

## Структура проекта

- config — настройки и конфигурация проекта.
- workplaces — приложение для хранения информации
  о рабочих местах.
- employees — приложение для хранения информации
  о сотрудниках.

## Используемые технологии

- Python
- Django
- SQLite
- Black
- Isort

## Установка и запуск

1. Создать виртуальное окружение.
2. Установить зависимости:

   pip install -r requirements.txt

3. Выполнить миграции:

   python manage.py migrate

4. Запустить сервер:

   python manage.py runserver
